## How It Works

### Step 1: Get Your Party Pass

Visit **redhorseoracle.com/party** and purchase a Party Pass.

Each pass includes **6 complete games** — enough for an entire evening of competition or multiple events throughout the CNY season.

### Step 2: Share Your Game Code

When you start a game, you'll receive a unique 6-character code (like **8478JL**).

Share this code with your guests. They can join from any device — no app download required, just a mobile browser.

### Step 3: Host the Game

As the host, you control the game flow:
- Start when everyone's ready
- Watch players answer in real-time
- See the leaderboard update after each question
- Move to the next question when ready

### Step 4: Compete & Celebrate

Players earn points based on:
- ✅ **Correct answers** — Base points for getting it right
- ⚡ **Speed bonus** — Faster answers earn more points
- 🔥 **Streak bonus** — Multiple correct answers in a row multiply your score

The leaderboard updates live. Cheers. Groans. Celebration. That's what makes it a party.
