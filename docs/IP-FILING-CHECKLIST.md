### Micro Entity vs Small Entity Status

**Micro Entity Requirements (50% fee reduction):**
- [ ] Gross income < $234,579 (2026 limit)
- [ ] Not named on more than 4 prior patent applications
- [ ] Not assigned/obligated to assign to entity with >4 patents

**Small Entity Requirements (50% fee reduction):**
- [ ] Less than 500 employees
- [ ] Not assigned to large entity

**Recommendation:** File as micro entity if qualified.

- [ ] Keep prompts in environment variables (not in code)

## PART 8: POST-FILING ACTIONS

### Once Patents Filed

- [ ] Add "Patent Pending" to:
  - Website footer
  - Marketing materials
  - Product packaging (if any)
  - README/documentation

- [ ] Update press materials with:
  > "Red Horse Oracle is protected by pending US patent applications covering privacy-preserving AI content generation and authenticated digital art distribution."

### Once Trademarks Filed

- [ ] Start using ™ symbol (TM #1™, TM #2™, etc.)
- [ ] Set up trademark watch service
- [ ] Document first use in commerce dates
- [ ] Keep specimens of use (screenshots, receipts)

### Once Copyrights Filed

- [ ] Update copyright notices:
  > "© 2026 PIGENAI LLC. All Rights Reserved."
- [ ] Keep copies of registration certificates
- [ ] Document any infringements for enforcement
